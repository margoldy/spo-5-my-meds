# Frontend

Frontend написан на Vue 3 и собирается через Vite. Это веб-реализация интерфейса мобильного приложения: на компьютере рабочая область ограничена шириной телефона.

## Структура

- `src/pages` — экраны приложения;
- `src/components/ui` — общие элементы интерфейса;
- `src/api` — запросы к backend;
- `src/store` — состояние приложения и действия над данными;
- `src/utils` — шифрование, даты, уведомления и локальное хранение.

Приложение хранит пользователя, курсы, расписание и историю в общем реактивном состоянии. API-модули отвечают только за HTTP-запросы, а подготовка данных и обновление состояния выполняются в `store`.

## Шифрование

Названия лекарств пользователя, заметки и дозировки шифруются в браузере через `AES-256-GCM` до отправки на backend. Случайный ключ медицинских данных защищается паролем через `Argon2id`; открытый ключ и пароль на сервер не передаются.
[src](../../frontend/src)
После разблокировки неэкспортируемый `CryptoKey` сохраняется в `IndexedDB` текущего браузера. Подробная схема описана в документе [«Шифрование медицинских данных»](encryption.md).

## Локальное хранение

- access token хранится в `sessionStorage` до закрытия вкладки;
- refresh token хранится в `localStorage`;
- настройки, остатки лекарств и аллергии медицинской карточки хранятся в `localStorage`;
- статистика не сохраняется отдельно, а рассчитывается из расписания и истории приёмов.

Локальные остатки и аллергии не отправляются в API и не синхронизируются между браузерами.

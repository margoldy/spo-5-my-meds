# Настройка и запуск backend

1. Перейдите в папку сервера:

```powershell
cd server
```

2. Создайте и активируйте виртуальное окружение:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
```


3. Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

4. Создайте PostgreSQL-базу с именем из `DB_NAME` (`aptechka_db` в примере).

5. Создайте файл `.env` на основе [`.env.example`](../../server/.env.example) и укажите данные подключения к PostgreSQL, ключ подписи токенов и настройки SMTP.

6. Создайте таблицы:

```powershell
python -m app.db.create_tables
```

Команда создаёт отсутствующие таблицы и добавляет в справочник 100 лекарств из Государственного реестра лекарственных средств Минздрава России. Уже существующие записи не дублируются и не изменяются. Если структура моделей изменилась во время разработки, пересоздайте учебную базу и выполните команду снова. При запуске API отсутствующие таблицы и записи справочника также создаются автоматически.

7. Запустите сервер:

```powershell
python -m uvicorn app.main:app --reload
```

Сервер: <http://127.0.0.1:8000>

Swagger: <http://127.0.0.1:8000/docs>

Проверка API:

```powershell
python -m pytest
```

# Локальный запуск

## Что понадобится

- Python 3.13;
- Node.js 20.19+ или 22.12+;
- PostgreSQL;
- почтовый ящик с паролем приложения для отправки кодов входа.

## Порядок запуска

1. Настройте PostgreSQL и запустите backend по [инструкции backend](backend/setup.md).
2. В отдельном терминале настройте и запустите frontend по [инструкции frontend](frontend/setup.md).

После запуска доступны:

- frontend: <http://127.0.0.1:5173>;
- backend: <http://127.0.0.1:8000>;
- Swagger: <http://127.0.0.1:8000/docs>.
